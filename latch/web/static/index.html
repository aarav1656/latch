Issue-anchored proof

Does this pull request fix the issue it claims to?

Paste a GitHub pull request that closes an issue. Latch writes a test from the issue text alone, runs it on the base commit and on the head, and keeps the receipt. A fix is proven only when the test fails before and passes after.

Public Python repositories. The pull request description must say Fixes #123.

Running live

    What happens when the gate stays shut

    If the proof test still fails on an agent's fix, a Nemotron coding agent rewrites the code and the harness runs everything again. The model never decides: the gate opens only when the frozen proof test is green and the repository's own suite stays green.
